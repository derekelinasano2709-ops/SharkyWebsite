SHARKY MEGALODON — SITIO ESTÁTICO

Contenido:
- index.html: página principal
- dashboard.html: panel interactivo de demostración (sin conexión real a Discord)
- terms.html: plantilla inicial de términos de uso
- privacy.html: plantilla inicial de política de privacidad
- styles.css: diseño responsive
- app.js: interacciones locales del dashboard
- shark.svg: emblema vectorial de tiburón

PRUEBA LOCAL:
Abre index.html en un navegador.

PUBLICACIÓN:
Puedes subir estos archivos a GitHub Pages o a otro hosting estático. Mantén todos los archivos en la misma carpeta.

IMPORTANTE:
El dashboard es solo una demo. Para conectar servidores reales se necesita OAuth2 de Discord, un backend/API seguro y autenticación/autorización. Nunca pongas el token del bot en HTML, JavaScript del navegador o repositorios públicos.

Antes de publicar términos y privacidad, completa los campos [entre corchetes] y verifica que el texto refleje el comportamiento real de Sharky.
